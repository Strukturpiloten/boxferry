# BoxFerry 0.2.0

- Adds `convert` and `validate` for Compose-to-Compose, Compose-to-Quadlet,
  Quadlet-to-Compose, and Quadlet-to-Quadlet routes.
- Adds ordered file/directory input, explicit Compose interpolation, safe empty-directory output,
  grouped diagnostic rules, JSON reports, and privacy-safe local error reports.
- Preserves unresolved expressions during native Compose-to-Compose canonicalization and expands
  loss-aware lifecycle, dependency, environment, security, topology, and resource mappings.
- Uses ComposeLens 0.1.17 and QuadletLens 0.1.13 from crates.io.
- Replaces old conversion syntax with
  `boxferry convert <INPUT_TYPE> <OUTPUT_TYPE>`; for example,
  `boxferry convert compose quadlet`.
- Changes `QuadletSource::parse` to return `QuadletParseResult` or `QuadletParseError`, preserving
  recoverable native findings.
- Supports Linux with Rust 1.85.0 or newer; Windows users run BoxFerry inside WSL2.
