# BoxFerry 0.1.1

- First crates.io publication of `boxferry` and its seven supported component crates.
- Includes the neutral model, conversion engine, Compose and Quadlet adapters, runtime
  reconstruction, and finite Docker and Podman inspection adapters.
- Keeps file, environment, runtime, and deployment side effects explicit; non-exact mappings
  remain structured outcomes requiring caller authorization.
- Supports Rust 1.85.0 and newer.
