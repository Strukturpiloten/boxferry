# Conversion guides

Choose the input row and output column.

| Input   | Compose output                                    | Quadlet output                                    |
| ------- | ------------------------------------------------- | ------------------------------------------------- |
| Compose | [Compose to Compose](convert/compose-to-compose/) | [Compose to Quadlet](convert/compose-to-quadlet/) |
| Quadlet | [Quadlet to Compose](convert/quadlet-to-compose/) | [Quadlet to Quadlet](convert/quadlet-to-quadlet/) |

Compose input can be interpolated explicitly. Quadlet input has no interpolation options.
