# Docker to Podman

This route is Unreleased development functionality. Read the [Docker acquisition, consent and
artifact contract](../../docker-input/) and [exact profile list](../../../reference/compatibility/#docker-development-boundaries).
Installed releases may expose fewer routes; source support does not establish native consumer,
application migration or release qualification.

Select a bounded read-only Docker source using an explicit local socket or conventional Linux
lookup and one selector family. Review reconstruction findings separately from target loss.
The [Docker input guide](../../docker-input/) defines no-match/ambiguity refusal, independent
source environment, bind, public-label and resource decisions. This offline command displays
options without connecting to a daemon:

<!-- boxferry-example: docker-to-podman-help -->

```console
boxferry convert docker podman --help
```

Podman output is `podman.json` plus `podman-commands.sh` for an explicitly chosen Podman context
and reviewed version (default 6.1.0). BoxFerry never executes the script. Protected inline values
remain subject to Podman's output refusal; Docker source consent does not override that boundary.
The resulting plan is not observed Podman input.

This page uses help rather than a live-host walkthrough so the documentation gate stays offline.
The authored synthetic socket journeys exercise source routes separately; help output alone is
not conversion or native/application acceptance evidence.
